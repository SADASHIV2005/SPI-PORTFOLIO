01 / Project brief

From four switches to a serial message.

SPI LINK demonstrates the transformation of parallel digital inputs into a timed serial stream, then back into a parallel output pattern.

◈

Problem

Parallel data requires multiple signal wires. Serial transmission sends bits sequentially using fewer data connections.

⌁

Solution

A 74HC165 captures the switch word, and a 74HC595 receives the serial stream and drives indicator LEDs.

◎

Learning outcome

Understand shift registers, clock synchronization, chip selection, data ordering, and digital circuit troubleshooting.

02 / System architecture

Every block has a job.

The communication path and the timing-control path are separate functions. Keeping them distinct makes the circuit easier to debug.

INPUT

Four DIP switches

Represent the data word D3–D0. Each input needs a defined logic level when its switch is open.

TRANSMITTER

74HC165 · PISO

Parallel-in/serial-out register. Loads a group of inputs, then shifts them toward the QH serial output.

TIMING

NE555 + 74HC393

The 555 can provide clock pulses. The counter can track clock events; additional sequencing logic may be needed to create a complete transaction.

RECEIVER

74HC595 · SIPO

Serial-in/parallel-out register. Receives bits through SER and updates output pins when RCLK latches the shift-register contents.

Design note: A 74HC393 is a binary counter, not a complete SPI controller. Confirm the clock count, reset, load, and latch sequence with logic probes or an oscilloscope.

Why these ICs?

ComponentRoleWhy it is used
74HC165Parallel → serialCaptures switch inputs in parallel and shifts them out over one data line.
74HC595Serial → parallelReconstructs received data and has a separate output latch.

Power and wiring checklist

Supply

Both ICs: pin 16 to +5 V and pin 8 to GND. Connect all grounds, including the timer and counter, together.

Decoupling

Place a 100 nF ceramic capacitor close to each IC between VCC and GND. Check the exact timer and counter pinouts separately.

Switches

Use pull-up or pull-down resistors so open switches never leave the 165 inputs floating. Add debouncing if switches initiate timing events.

LEDs

Use one current-limiting resistor per LED. Verify polarity and keep the IC within its specified output-current limits.

Signals in plain language

MOSI
What bit is being sent?

The serial data line from Master to Slave. The receiver must sample it at the correct clock edge.

SCLK
When is the bit shifted?

Clock edges advance the registers. The chosen edge and data setup time must match the circuit timing.

CS
Which transaction is active?

Chip-select polarity is implementation-dependent. A conventional active-low CS is LOW during selection, but it is not automatically the 165 load signal or the 595 latch signal.

RCLK
When do LEDs update?

The 595 copies its shift-register contents into the output register on the RCLK rising edge.

Transaction sequence

1. Set inputs

Configure D3–D0 using the DIP switches.

2. Load

Pulse SH/LD LOW to capture the parallel inputs; then return it HIGH for shifting.

3. Shift four bits

Apply four suitable clock pulses and check the MOSI data at the receiver's sampling edge.

4. Latch

After the correct word has arrived, pulse RCLK LOW-to-HIGH to update the output register.

5. Verify

Compare the four LED states against the original DIP word. Repeat with different patterns.

05 / Timing design

Clock generation is not transaction control.

The NE555 can generate a periodic clock. A counter can count edges. A complete four-bit interface must also establish a correct load window and a latch event.

NE555 astable clock

RA, RB, and the timing capacitor set the approximate oscillator frequency. For a conventional astable arrangement:

f ≈ 1.44 / ((RA + 2RB) × C)

This estimate assumes the usual 555 astable topology. Actual frequency depends on component tolerance and the specific circuit.

74HC393 pulse counter

The counter can count clock transitions and supply divided-frequency outputs. Its ripple outputs are not automatically a clean four-pulse CS generator.

Use appropriate reset and decoding/sequencing logic, and verify output transitions with probes before connecting to the registers.

Timing acceptance criteria: one intentional parallel load, exactly four effective shift events, valid data at each sampling edge, and one output-latch edge after the fourth bit. The precise CS waveform and clock mode should be documented from the final schematic.

08 / Outcome

A small circuit. A foundational concept.

SPI LINK brings together parallel-to-serial conversion, serial-to-parallel reconstruction, clock synchronization, and output latching in an observable digital system.

Applications

Digital electronics labs, serial-interface demonstrations, and hardware prototyping.

Limitations

Four-bit payload, discrete timing logic, and a need for careful sequencing and validation.

Future scope

Bidirectional transfer, eight-bit operation, PCB integration, and measured timing analysis.
